# 율그룹건축사사무소 홈페이지

## 열기 및 배포
index.html을 브라우저에서 열면 시작합니다. 정적 웹 호스팅에는 이 폴더의 HTML 파일과 assets 폴더를 함께 업로드합니다. 별도 설치나 빌드는 필요하지 않습니다. 공개 배포는 아직 진행하지 않았습니다.

## 배포 전 마지막 확인 (의뢰인 확인 필요)
- [ ] 회사 연락처·사업자등록번호·대표이사 경력 표기 최종 확인
- [ ] 익산 신동 청솔아파트(09), 오성대우아파트(08): 실적 목록의 어느 항목과 같은 프로젝트인지 확인 후 연도·규모 추가
- [ ] 고우당(05) 용도 확인 (현재 '일반건축'으로 표기)
- [ ] 이미지가 없는 4개 프로젝트(03·04·05·06) 사진 확보 여부
- [ ] 도메인이 정해지면 모든 페이지의 `og:image` 값을 `https://도메인/assets/og-image.jpg` 형태의 전체 주소로 바꾸기 (카카오톡·페이스북 공유 미리보기는 전체 주소가 있어야 이미지가 뜹니다)
- [ ] 문의 양식을 메일 앱 방식으로 둘지, 폼 전송 서비스(예: Formspree, 구글 폼)를 붙일지 결정

## 배포 방법
정적 호스팅(Netlify, Cloudflare Pages, GitHub Pages, 일반 웹호스팅)에 이 폴더 전체를 올리면 됩니다. 빌드 과정은 없습니다. `README.md`는 올리지 않아도 됩니다.
- `404.html`: 없는 주소로 들어왔을 때 보이는 페이지입니다. 사이트가 도메인 최상위(`/`)에 있을 때 정상 동작합니다.
- `robots.txt`, `favicon.ico`, `assets/apple-touch-icon.png`, `assets/og-image.jpg` 포함.
- 배포 후 네이버 서치어드바이저·구글 서치콘솔에 사이트를 등록하면 검색 노출이 빨라집니다.

## 2026-11-04 납품 전 정리
- 내용: 프로젝트 번호 표기를 `PROJECT / 번호`로 통일, 고우당 분류 오류(지역명 '군산'이 분류로 들어가 있던 것) 수정, 반디나래지원센터를 실적 목록대로 '노유자시설'로 표기, 법학전문대학원 이미지 번호를 종류별로 다시 매김
- 프로젝트 07·10~17: 사이트 실적 목록에 있는 연도·용역명·세대수를 근거로 설명과 '관련 실적'을 추가 (새로 지어낸 정보 없음)
- 연혁: 수상작 이름에서 해당 프로젝트 페이지로 연결
- 사무소 소개: 법학전문대학원 사진 추가
- 오시는 길: 지도가 없는데 '아래 지도에서'라고 되어 있던 문구 수정, 문의 양식에 메일 앱이 안 열릴 때 안내 추가
- 디자인: 한글 단어 중간에서 줄이 바뀌던 문제 해결, 넓은 화면(1600px 이상)에서 본문이 왼쪽으로 치우치던 정렬 수정, 연도 글꼴을 제목 글꼴(마루부리)로 통일, 이미지 없는 프로젝트 카드에 수상 내역 표시, 맨 위로 버튼은 스크롤했을 때만 표시, 태블릿에서 홈 대표 프로젝트 3열 배치
- 배포 준비: 브랜드 파비콘·홈 화면 아이콘, 공유 미리보기 이미지와 메타 태그, 프로젝트별 검색 설명문, 404 페이지, robots.txt

## 2026-09-23 반영 사항
- 율그룹.zip의 이미지 15장을 13개 프로젝트에 모두 반영했습니다.
- 기존 이미지 미제공 프로젝트 4개는 기록 페이지로 유지했습니다. 총 17개 프로젝트, 전체 22개 페이지입니다.
- 일반건축·공동주택·스마트팜 분류와 프로젝트명 검색, 관심 프로젝트 필터를 연결했습니다.
- 각 상세 페이지에 이미지 확대, 이전·다음 이미지, 키보드 화살표 이동, 닫기 기능을 추가했습니다.
- 조감도와 건축 사진을 구분했습니다. 미제공 규모·연도·준공 여부는 새로 만들어 넣지 않았습니다.
- 전북대학교 법학전문대학원 파일명의 오타를 기존 회사 실적 표기에 맞춰 정리했습니다.
- 15개 원본은 변경하지 않았고 웹용 WebP 30개(목록용·상세용)로 최적화했습니다. 총 약 8.4MB입니다.
- 마루부리와 SUIT를 로컬 웹폰트로 포함하여 외부 폰트 서버 없이 표시됩니다. 라이선스 전문은 assets/fonts 폴더에 있습니다.
- 오시는 길은 주소와 주소 복사, 네이버 지도·카카오맵 연결 방식으로 정리했습니다.

## 기능
실적 검색, 용도·연도 필터, 정렬, 검색 조건 주소 복원, 프로젝트 저장, 모바일 메뉴, 인쇄/PDF 저장, 연락처 연결, 이메일 문의 초안 작성을 지원합니다.

문의 양식은 사이트에서 바로 전송하지 않고 사용자의 메일 앱을 엽니다. 관심 프로젝트는 같은 브라우저에 저장됩니다. 지도 연결과 메일 발송은 외부 서비스와 사용자 환경에 따릅니다.

## 검증
2026-11-04: Chromium으로 1920·1440·768·390px × 23개 페이지 화면 확인, 내부 링크·리소스 60개 점검, 스크립트 오류·가로 넘침 없음, 분류·검색·탭·이미지 확대·저장·모바일 메뉴 동작 확인.

2026-09-23:
- Chromium 기반 Edge: 320·360·390·430·768·844·1440px × 22개 페이지, 154개 화면 조합
- WebKit 26.5: 320·390·768·844px × 22개 페이지, 88개 화면 조합
- 총 242개 화면 조합, 83개 내부 페이지·리소스 링크 점검
- 스크립트 오류 및 본문 가로 넘침 없음
- 폰트 두 종류 실제 로딩 확인
- 검색·분류·연도 필터·초기화·저장 유지·모바일 메뉴·이미지 확대/이동/닫기·문의 필수값 검증 확인
- 실제 아이폰 또는 안드로이드 기기를 사용한 점검은 아닙니다. WebKit 검증은 Windows에서 모바일 화면을 모사한 결과입니다.
- 실제 이메일 전송과 지도 앱 내부 길찾기는 실행하지 않았습니다.
